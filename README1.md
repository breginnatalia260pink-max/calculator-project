# Назва проєкту
"Простий калькулятор" сторений для швидкого обчилення простх завдань 
## Опис
Проект може виконувати найпростіші завадння між двома числами. А імено операції такі як додавання, віднімання, піднятя до степення, ділення, множеення і %.
## Функціональність
- Від двох чисел
- Обрахування рівння за домогою оперіції
- Вивід результату обчислення
## Вимоги
- Python 3.7+
## Встановлення
1. Завантажте проєкт на свій комп’ютер:
bash
git clone https://........
Будьте обачні, використовуючи код.
2. Відкрийте папку з проєктом:
bash
cd calculator-project
Будьте обачні, використовуючи код.
3. Запустіть калькулятор:
bash
python calculator.py
Будьте обачні, використовуючи код.
## Використання
=== Простий калькулятор ===
Операції: +, -, *, /, **, %
Для виходу введіть ‘exit’
Введіть операцію (+, -, *, /, **, %) або ‘exit’: -
Введіть перше число: 12
Введіть друге число: 24
Результат: -12.0
Введіть операцію (+, -, *, /, **, %) або ‘exit’: /
Введіть перше число: 4
Введіть друге число: 16
Результат: 0.25
